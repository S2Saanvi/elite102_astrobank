Project Description: 
The goal of the project was to create an online banking experience for a user to access their bank account or to create a new bank account.

Setup Instructions:
1. Go to the directory where the app.py file exists
2. Check to ensure flask is installed. If not install flask using the command
pip install flask
3. Once flask is installed run
python app.py
4. Click the link on the bottom right corner and open the browser to access the application

Features: 
- Create Account
- Withdraw
- Deposit
- View Balance
